# TechShop – Android E-commerce Application

TechShop is an Android e-commerce project consisting of a customer
application, a manager/admin application, and a PHP/MySQL backend API.

The project was developed to demonstrate a complete mobile e-commerce
system with product browsing, shopping cart, order processing,
product management, and communication between Android applications
and a backend server.
